# 🔐 Задание 3. Оценка Data Encryption at Rest and In Transit

## Классификация данных и инструменты защиты

| Данные                             | В чём необходимость защиты                                      | Инструменты защиты                                  |
| ---------------------------------- | --------------------------------------------------------------- | --------------------------------------------------- |
| Персональные данные (PII)          | Защита от утечки, соответствие законодательству РФ              | Шифрование AES-256, TLS 1.3, RBAC/ABAC, Vault       |
| Медицинские данные (SPII)          | Конфиденциальность, предотвращение несанкционированного доступа | Тегирование данных, шифрование БД, HSM, Vault       |
| Финансовые данные                  | Защита от мошенничества, предотвращение финансовых потерь       | Шифрование TLS, PCI DSS, шифрование на диске и в БД |
| Лог-файлы и аудиторские данные     | Обеспечение аудита, расследование инцидентов                    | SIEM-системы, централизованный сбор логов, DLP      |
| Данные в передаче (In Transit)     | Защита от перехвата, MITM-атак                                  | TLS 1.3, VPN, Mutual TLS                            |
| Данные в состоянии покоя (At Rest) | Защита от физического доступа и взлома                          | Full Disk Encryption, шифрование на уровне БД, HSM  |

---

## Рекомендуемые средства автоматизированного контроля

- Системы мониторинга доступа (Audit Logging, SIEM)
- Алерты на подозрительную активность
- Инструменты Data Loss Prevention (DLP)
- Автоматическое сканирование и ревизия метаданных (например, через Apache Atlas)
- Централизованное управление ключами (KMS, Vault)

---

## Пример реестра программных и аппаратных средств защиты

| Средство                       | Назначение                     | Комментарии                                                 |
| ------------------------------ | ------------------------------ | ----------------------------------------------------------- |
| TLS 1.3                        | Шифрование данных в передаче   | Рекомендуется для всех внешних и внутренних соединений      |
| AES-256                        | Шифрование данных на диске     | Для БД и файловых систем                                    |
| HashiCorp Vault                | Управление ключами и секретами | Централизованное хранилище ключей                           |
| Apache NiFi                    | Очистка и маршрутизация данных | Позволяет применять политики защиты на уровне потока данных |
| HSM (Hardware Security Module) | Аппаратное хранение ключей     | Для максимальной безопасности ключей                        |
| SIEM (например, ELK Stack)     | Мониторинг и аудит             | Централизованная обработка логов                            |
